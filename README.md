# ivalkenburg/tap

Homebrew casks and formulae for my apps and command-line tools.

```sh
brew install ivalkenburg/tap/<name>
```

| Name | Type | What it is |
| --- | --- | --- |
| `spotlite` | Cask | [Spotlite](https://github.com/ivalkenburg/spotlite), a lightweight application launcher for macOS 26 |
| `shlog` | Formula | [shlog](https://github.com/ivalkenburg/shlog), a CLI for inspecting and cleaning up zsh, bash and fish history |
| `goblet` | Formula | [goblet](https://github.com/ivalkenburg/goblet), a static file server for local development |
